1. PROJECT TYPE & STACK
================================================================================

Project Name : Masrafji (مصرفجي) — "Your Money, Personalised"
Type         : A premium personal finance web application demo with role-based
               onboarding, personalized dashboards, and smart notifications.

TECH STACK
----------
- Runtime         : React 19 (latest, hooks-based architecture)
- Build Tool      : Vite 8 with Rolldown
- Styling         : Tailwind CSS 3 with custom HSL CSS variable design tokens
- Charting        : Recharts (v3.8.1) for cash flow, donut, and forecast charts
- Icons           : Lucide React (v1.12.0) — extensive icon library
- i18n            : Custom React Context-based bilingual system (English/Arabic)
- State           : React hooks (useState, useContext) — NO Redux/Zustand
- Build Optim.    : Vite with manual chunk splitting (recharts/lucide/react)

LANGUAGES
---------
Fully bilingual:
- English (LTR) : Default, Inter font family
- Arabic  (RTL) : Full support with Tajawal font, mirrored layouts,
                  Arabic-Indic numerals
- Auto-detection from browser language (falls back to English)

STYLING FRAMEWORK
-----------------
- Tailwind CSS 3 with custom color palette (brand blue: #3961fb)
- Custom box shadows (soft, lift, ring)
- Custom animations (fade-in, slide-up, pop-in, shimmer, float)
- Dark mode support via class-based ([data-theme="dark"]) +
  respects prefers-color-scheme
- Respects prefers-reduced-motion for accessibility

STORAGE   : localStorage only (no backend API — fully client-side)
DEPLOY    : Static Vite bundle, runs entirely in the browser

================================================================================
14. ERROR HANDLING & EDGE CASES
================================================================================

LOCALSTORAGE ACCESS
- All ops wrapped in try/catch
- If unavailable: defaults to light theme, EN, USD
- Graceful degradation

MISSING DATA
- Invalid roleId → uses DASHBOARD_DATA.general
- Invalid goal/income → first available
- Invalid currency → USD

NULL / UNDEFINED
- pick(obj, field, lang) checks obj first
- fmtMoney(amount, currency) coerces to USD if not found
- Chart data validated before render

BROWSER COMPATIBILITY
- ES2020+ (modern JavaScript)
- ResizeObserver, CSS custom properties → IE not supported
- Flexbox, Grid widely supported

MOBILE vs DESKTOP
- Single responsive codebase
- Touch-friendly (44 px+ tap targets)
- Tap/scroll only — no swipe gestures

================================================================================
15. NOTABLE ARCHITECTURE DECISIONS
================================================================================

 1. No backend API — fully client-side demo; data hardcoded in data.js
 2. Custom i18n (not react-i18next) — lightweight for demo
 3. Context for state, not Redux — app is small
 4. Recharts over D3/Chart.js — better React integration
 5. Tailwind CSS only, no styled-components — lean bundle, CSS vars for dark mode
 6. localStorage, not IndexedDB — simpler API; sufficient
 7. No build-time i18n extraction — translations are JS objects
 8. Role-specific data, not dynamic queries — clear personalization showcase
 9. Mock forms (no persistence) — clarifies demo intent
10. Notification ranking via heuristics — simple ID match
